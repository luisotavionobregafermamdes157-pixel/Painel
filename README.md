# FloatingPanel

Painel Android flutuante baseado no HTML. Os controles são apenas visuais/simulados: não injeta código, não modifica o Free Fire e não implementa aimbot/ESP/anti-ban.

## Build
No Android Studio: abra esta pasta e gere o APK.

No Termux, com Android SDK/Gradle configurados:
`gradle assembleDebug`

APK: `app/build/outputs/apk/debug/app-debug.apk`
